## 📌 About this utility
This software automates repetitive tasks in the Roblox game Pet Simulator 99. It runs on Windows systems. You use it to save time on farming coins, opening eggs, and managing your inventory. The script handles quest progression and helps you find items in trading booths without manual input.

* Software: AutoHotkey v2 installed on your computer.
* Input: A standard mouse and keyboard.
* Screen resolution: 1920x1080 is the recommended setting for correct button detection.

## 🎮 How to use the script
Once the script runs, a menu appears on your screen. You select features by clicking the corresponding boxes in this menu.

### Automated farming
To start farming, enter the game area and press the Start Farming button. The script detects coin piles and moves your character to collect them. It loops this process until you stop the script.

### Egg handling
Use this feature to hatch eggs while you stay away from the keyboard. The script handles the interaction screen and clicks the hatch button automatically. Ensure your character stands near the egg machine before you enable this.

### Loot collection
The loot collector scans the ground for items dropped by chests or breakables. It pathfinds to these items and retrieves them. Enable this alongside farming to keep your inventory full of rewards.

### Quest and rank progression
This mode targets specific objectives required to rank up. It identifies active quest requirements within the game menu and performs the necessary actions, such as breaking specific objects or spending currency.

### Teleport controls
The script includes a teleport panel. This allows you to jump between game zones without walking. Select your destination from the list and the script triggers the appropriate movement commands.

### Booth search
Find specific pets in trading booths using the search tool. Type the name of the pet you want. The script scans nearby booths and reports the price.

If the script does not click the correct buttons, check your screen scaling settings in Windows. Set your display scale to 100%. Ensure your game graphics settings match the default resolution requirements. 

If the script closes unexpectedly, verify that your antivirus software does not block the AutoHotkey process. You may need to add an exception for the script folder in your security settings.

If the game updates, wait for a new version of this script. Developers often push updates to this page following major game patches. Check the releases section regularly for these improvements. 

Always keep your AutoHotkey version updated to the latest v2 release. Older versions will cause errors when you try to run the script. Delete the old version from your computer before you install the new one to prevent conflicts.
